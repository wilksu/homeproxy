# 原生配置模式已移除

项目现统一使用节点设置管理手动节点及订阅导入的节点／组，并在自定义路由中配置路由、DNS 和规则集。

已移除完整配置管理页、原生路由模式、对应 RPC／ACL、配置生成分支及定时订阅更新器。节点设置解析 sing-box JSON 订阅的能力保留。旧 `/etc/homeproxy/profiles/` 文件仍作为用户数据备份保留，不再被运行链路读取。

开发容器的 GLaDOS 策略已一次性迁入 UCI：2 个 DNS 服务器、5 个规则集、11 条显式路由规则和 3 条 DNS 规则。DNS 劫持入口与嗅探由自定义路由统一生成。默认出站引用节点库的 Proxy，默认出站 DNS 引用 local，DNS 默认服务器引用 google。原有自定义策略被保留并禁用，迁移前配置及原始文件保存在私有 `.dev/before-native-removal/`。

为保留现有组合 DNS 条件，DNS 规则增加“排除的规则集”：其他匹配条件 AND NOT（排除的规则集）。这不是整份 JSON 的隐藏透传；字段可在自定义路由表单编辑。

这次是对当前开发容器已知配置的迁移，不提供任意完整配置的自动转换。其他旧安装若仍选择已移除模式，生成器会拒绝该模式，避免把它误当作普通模式执行；应先备份并迁移策略再升级。

## 本次修正

1. UDP NAT mapping/filtering、最大映射数、超时不应仅依赖 custom 分流策略。现在五种策略中，只要对应 UDP 代理启用就可见；普通模式关闭 UDP 时隐藏。TUN 网络栈按代理方式显示。
2. 所有策略统一读取 routing.udp_timeout；缺省回退旧 infra.udp_timeout，再回退 300 秒。保留已有设置兼容。
3. 普通模式禁用 UDP 时，不再生成可能落到随机端口的 TProxy UDP 入口。
4. 移除 TUN 栈说明依赖相邻 DOM 的写法，使用正常表单说明。
5. 观测设置在未创建服务端端口字段时不再因空 lookupOption 抛异常。
6. 订阅更新写回清理后的 TCP/UDP URLTest 成员列表；保留明确关闭的主节点与 UDP 选择；修正路由模式默认值拼写。
7. 更新后的配置无法启动时明确报告未激活并返回失败，不再输出更新成功。
8. 观测日志去除 ANSI 颜色控制序列，保留文本内容。
9. 补齐当前前端字面量中缺少的 22 条中文词条及模板。没有编译 LMO，容器当前英文页面不代表中文包已安装验证。

## 参数关系

UDP NAT 参数控制 sing-box UDP 入站的会话行为，不是路由器防火墙 NAT 开关，也不决定大陆白名单等分流策略。代理方式决定使用 TProxy 或 TUN；路由策略决定收到流量后往哪个出站走。

自定义模式仍单独展示默认出站、自定义 DNS 和路由规则等策略字段；这部分不应为了表面统一而全部显示在普通模式。

## 仍有差距 / 尚未验证

- **“启用即加载”尚未实现。** 当前仍按默认出站、路由、DNS、规则集引用及组/拨号依赖加载；不是加载整个节点库。旧 routing_node 兼容代码仍存在，不能声称整个旧模型已删除。
- 原生订阅只做支持类型与字段的结构化转换，不能宣称完整覆盖 sing-box 原生配置；多 peer WireGuard 等导入能力仍有限。具体见 node-library-and-types.md。
- 17/12 种类型已切换检查，不代表所有协议选项的笛卡尔积、每种协议保存应用和实际连接都经过验证。
- 实体路由器 LAN 透明代理、防火墙/TUN 接管、IPv6 实际链路、不同节点 UDP、多 IP 故障与回包丢失、WireGuard/Tailscale 真正联网、ACME 签发尚需对应环境。
- 512 MiB 真机持续负载、内存与吞吐没有验收；容器正常不能代替设备测试。
- 配套软件包 CI 构建和实际安装升级、中文 LMO 显示未验收，遵守不在本地编译的要求。
- 布局仍有可进一步收敛之处，例如观测设置未展开密钥时有一行空展示区域；本轮不将截图可读性检查描述为全面视觉验收。

总体：已修正可复现的字段依赖、生成配置和更新反馈问题；已有测试覆盖的链路通过，但不能据此宣布全部兼容和真机功能验收完成。

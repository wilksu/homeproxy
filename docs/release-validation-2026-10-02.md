## 发现并修复的问题

1. **证书上传链路失效**：前端绑定参数顺序错误；后端调用了不存在的 `is_binary`，对常见 PKCS#8、证书链和 ECH 入口支持也不完整。修正调用、PEM 检查和目标白名单；以 0600 临时文件写入，交由 sing-box 专用账号持有，再在成功后替换；失败保留原文件。归属接口使用 [ucode fs.chown](https://ucode-lang.org/module-fs.html#chown)，并以专用账号实际验证可读。
2. **REALITY 等生成按钮生成空结果**：后端总给零参数命令追加一个空字符串。改为只传非空参数，并检查命令状态及完整输出。实际按钮复验公私钥均为 43 字符；真实核心回归覆盖 REALITY、WireGuard、VAPID、UUID 和 ECH。
3. **订阅失败不显示错误**：`cgi-exec` 的 HTTP 200 不代表子进程成功。增加仅写角色可执行的包装脚本，返回明确退出码；页面据此显示失败，不再将失败当成成功刷新。
4. **网络质量完成后耗时变为 0 秒**：最终 API 消息省略耗时，解码默认值覆盖了进度。现在保留本轮已收到的最大耗时，下次测试重新计时。
5. **分享链接弹窗说明不符合实现**：明确每行一个分享链接、去重，以及 JSON/SIP008 应通过订阅 URL 导入。

另发现开发容器原防火墙配置开启了宿主内核不支持的 flow offloading，导致整个 fw4 规则加载失败。在容器配置中关闭软/硬件 flow offloading 后，规则检查和加载通过，才完成上述透明 TCP/UDP 验证。这是开发环境适配，没有修改产品默认防火墙设置。

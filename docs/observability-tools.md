# Observability 工具（1.14.0）

连接页支持活动／全部／已关闭过滤，按建立时间、上传或下载总量降序排列，以及确认后关闭所选核心全部连接。历史仅限当前页面收到的记录，最多 5000 条，刷新、切页或核心重置后不持久保留。

工具页使用现有 gRPC-Web 代理和运行中出站列表。STUN 显示外部地址、延迟及核心返回的 NAT 映射／过滤分类；服务器不支持分类时明确显示未知，不把 UDP 回包等同于完整 NAT 验证。网络质量测试由用户手动启动，设置 20 秒核心测试时限，展示容量、空闲延迟和 RPM；不自动执行。取消中止浏览器请求；核心结束时间仍取决于后端对断开和超时的处理。

Tailscale 接入状态、登录链接、设备列表与 Ping。未实现 Dashboard 的 SSH 终端、Taildrop 文件传输、证书和出口管理等完整工具，不能声称与官方完全等价。状态订阅失败在本区显示，不影响整个 Observability 的连接状态。

已验证容器页面、出站加载、真实 STUN 回包与取消、无 Tailscale 端点空状态，以及新增消息解码测试。未实际运行网络质量吞吐测试，也未在真实 Tailnet 验证 Ping。没有编译核心或前端；接口消息定义同步更新了 schema 和现有浏览器文件，构建脚本仅更新白名单以便以后生成时保留定义。

## 转发与设置收敛

长连接由有时限的后台任务承载；CGI 只创建任务、读取增量字节或标记取消，每次请求均校验 LuCI 会话和对应读／写权限。后台 curl 保留 55 秒上限；页面每 500ms 获取增量（最多 256KiB/次），读取速率带来的正常额外展示延迟约为 0–500ms。任务启动冲突会短暂重试。

取消标记由后台约每秒检查并终止对应 curl；页面失联且超过 8 秒没有续租时同样退出。已完成但无人读取的任务额外保留最多 10 秒。每个会话最多 6 个任务、全局最多 12 个；文件上限采用 shell `ulimit -f 1024`（计量单位随 shell，一般为 512KiB–1MiB）。超限或异常断流会作为失败返回，不伪装为成功。临时目录权限为 0700，密钥仅存在该私有目录和核心配置中。进程异常留下的目录在后续任务创建时清理超过 90 秒的记录。

保留 uHTTPd max_requests=3，容器验证概览加 3 条额外订阅时其他 LuCI 页面 5 次请求均返回 200，耗时 11–56ms。页面关闭后任务目录清空。此结果是开发容器验证，不代表 MT7986A 真机性能基准；后台 shell/curl 和短请求仍有进程及 CPU 开销。

独立 API and Dashboard 菜单已删除，设置集中在 Observability 弹窗。API 自动启用且默认仅监听 127.0.0.1；只有启用局域网连接后才显示来源、密钥和高级网络参数。Compose 已移除 8081 映射与 Dashboard 资源挂载。本地 Dashboard 安装配方和下载步骤均已移除。
